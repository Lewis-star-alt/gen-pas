# 🔐 Генератор безопасных паролей

Простой, но мощный генератор безопасных паролей, написанный на Rust. Создает криптографически стойкие пароли с настраиваемыми параметрами.

## ✨ Возможности

- **Настраиваемая длина** пароля (по умолчанию 12 символов)
- **Различные наборы символов**:
  - Прописные буквы (A-Z)
  - Строчные буквы (a-z)
  - Цифры (0-9) - опционально
  - Специальные символы (!@#$% и др.) - опционально
- **Исключение похожих символов** (o, O, 0, l, I, 1) для улучшенной читаемости
- **Генерация нескольких паролей** за один запуск
- **Оценка сложности** пароля
- **Гарантированное включение** всех выбранных типов символов

## 🚀 Установка

### Требования
- Установленный Rust и Cargo (версия 1.70.0 или выше)



### Сборка из исходников
```bash
# Клонируйте репозиторий
git clone 
cd gen-pas

# Соберите и установите
cargo install --path .

После установки программа будет доступна глобально как `gen-pas`.

# Или просто соберите для запуска
cargo build --release
./target/release/gen-pas --help
```

## 📖 Использование

После установки через `cargo install` вы можете использовать программу напрямую:

### Базовое использование
```bash
# Генерация пароля длиной 12 символов (по умолчанию)
gen-pas
```

### С параметрами
```bash
# Пароль из 16 символов с цифрами и спецсимволами
gen-pas -l 16 -d -s

# То же самое с длинными опциями
gen-pas --length 16 --digits --special

# Исключить похожие символы
gen-pas -l 14 -d -s -e

# Сгенерировать 5 паролей
gen-pas -c 5 -l 10 -d

# Только буквы, исключая похожие символы
gen-pas -l 12 -e
```

### Параметры командной строки

| Опция | Короткая | Длинная | Значение по умолчанию | Описание |
|-------|----------|---------|----------------------|-----------|
| Длина | `-l` | `--length` | 12 | Длина пароля в символах |
| Цифры | `-d` | `--digits` | false | Включить цифры (0-9) |
| Спецсимволы | `-s` | `--special` | false | Включить специальные символы |
| Исключить похожие | `-e` | `--exclude-similar` | false | Исключить похожие символы (o, O, 0, l, I, 1) |
| Количество | `-c` | `--count` | 1 | Количество генерируемых паролей |

## 🔒 Безопасность

- Использует криптографически безопасный генератор случайных чисел (`rand::thread_rng`)
- Гарантирует минимум по одному символу каждого выбранного типа
- Минимальная длина пароля - 4 символа
- Исключает визуально похожие символы по требованию

## 📊 Оценка сложности

Программа оценивает сложность пароля по следующим критериям:

- **🔴 Слабый**: 0-2 критерия
- **🟡 Средний**: 3-4 критерия  
- **🟢 Сильный**: 5 критериев

**Критерии оценки:**
- Наличие прописных букв
- Наличие строчных букв
- Наличие цифр
- Наличие специальных символов
- Длина ≥ 12 символов

## 🎯 Рекомендации по использованию

1. **Для важных аккаунтов** используйте пароли длиной не менее 16 символов со всеми типами символов
2. **Включите исключение похожих символов** если пароль будет вводиться вручную
3. **Используйте менеджер паролей** для хранения сгенерированных паролей
4. **Никогда не используйте один пароль для нескольких сервисов**
